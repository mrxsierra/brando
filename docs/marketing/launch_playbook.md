# **Brando Launch & Marketing Growth Playbook**

This document outlines the official launch campaign strategy, social copy templates, community distribution channels, and organic growth tactics for **Brando**.

---

## **1. Core Messaging & Value Proposition**

*   **Elevator Pitch**: Brando is a data-driven, 100% offline computational naming intelligence engine for tech startups, open-source packages, and brand strategists. It replaces subjective naming guesses with quantitative metrics across visual geometry (Bouma silhouettes), sound symbolism, esoteric alignments (Chaldean & 108 Nakshatra Padas), trademark clearance, and sub-35ms typosquatting security checks.
*   **Key Differentiators**:
    1.  **100% Free & Local**: Zero API costs, zero cloud lock-in. Powered by local C++ SIMD RapidFuzz and lazy gzipped dictionaries.
    2.  **3-Layer Engine**: Core phoneme synthesis + 8 vocabulary enrichment strategies + 3 orthographic post-passes.
    3.  **Native MCP AI Agent Integration**: Native 8-tool Model Context Protocol (MCP) server for Cursor, Claude Desktop, and AI coding agents.
    4.  **WASM In-Browser Playground**: Live Pyodide demo on `https://brando.dev/playground` allowing instant config building without local installation.

**Title**: `Show HN: Brando – Computational Naming Engine for Tech & Open Source`

**Post Body**:
> Hey HN,
>
> I built **Brando** ([github.com/mrxsierra/brando](https://github.com/mrxsierra/brando)), an open-source computational naming engine that converts qualitative branding research into quantitative, filterable metrics.
>
> **The Problem**: Naming a startup or open-source package is usually a messy mix of subjective guesswork, domain squatters, and accidental trademark collisions.
>
> **How Brando Solves It**:
> - **3-Layer Naming Engine**: Blends neoclassical roots, portmanteaus, and sound symbolism with orthographic post-passes.
> - **5 Technical Feature Modules**:
>   1. *Visual Geometry*: Bouma silhouette ascender/descender ratio and visual symmetry scoring.
>   2. *Sound Symbolism*: Plosive vs. Fricative sound ratios and industry perception affinity.
>   3. *Esoteric Alignments*: Pythagorean/Chaldean numerology & Vedic Nakshatra 108 Pada starting sound checks.
>   4. *Trademark Clearance*: Nice Class directory mapping & WIPO Madrid Protocol simulator.
>   5. *Typosquatting Protection*: Sub-35ms RapidFuzz SIMD & BK-Tree metric space search over top 1,000 global tech brands.
> - **Native MCP AI Server**: Connects directly to Cursor and Claude Desktop as an autonomous naming agent tool.
> - **100% Offline & Local**: Runs entirely on your machine via Python library (`import brando`) or CLI (`brando build`).
>
> You can try the live WASM in-browser playground at [https://brando.dev/playground](https://brando.dev/playground) or install via PyPI (`pip install brando`).
>
> I'd love your feedback on the phoneme synthesis rules and sound symbolism weights!
