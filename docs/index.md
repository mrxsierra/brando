# brando. — Systematic Brand Creation & Research Framework

Welcome to the official documentation portal for **`brando.`**.

`brando.` is an open-source, developer-first framework for brand name synthesis, phonetic euphony scoring, visual geometry analysis, trademark vetting, and RapidFuzz SIMD security checks.

---

## 🚀 Key Framework Features

- **3-Layer Generation Engine**: Neoclassical Latin/Greek root synthesis, 8 vocabulary enrichment strategies, and orthographic post-pass transforms.
- **Visual Geometry & Bouma Silhouette** (`brando.modules.visual`): Ascender, descender, and visual balance scoring.
- **Phonetic Euphony Scorer** (`brando.modules.phonetic`): Sound symbolism analysis across IPA phoneme charts.
- **Esoteric Numerology & Astrology Engine** (`brando.modules.esoteric`): Pythagorean, Chaldean, and 108 Nakshatra Pada computations.
- **Sub-35ms RapidFuzz Security Engine** (`brando.modules.security`): Typosquatting search against top 1,000 brand registries.
- **Click CLI Suite & Python SDK**: Interactive CLI wizard (`brando init`, `brando build`, `brando filter`) and programmatic `brando.Pipeline` SDK.
