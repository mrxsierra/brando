# Press Kit & Official Brand Asset Suite

Download official vector logo assets, visual monograms, banners, and design token specifications for **`brando.`**.

---

## Official Brand Identity & Archetype

**`brando.`** uses a **Sovereign Typemark** archetype built on architectural precision and high-fidelity minimalism:

- **Execution Accent Dot (`.`)**: Represents completion, execution, and developer tool conventions (e.g. `bun.`, `deno.`).
- **Slate Navy Canvas**: High-contrast obsidian navy (`#090D16`) paired with Execution Blue accent highlights (`#2563EB`).

## Brand Usage Guidelines

- **Do**: Use the official SVG vector assets when linking to `brando.` in articles, open-source documentation, or media coverage.
- **Do**: Maintain the execution period dot (`brando.`) when displaying the official typemark name.
- **Don't**: Alter the aspect ratio, skew the monogram typography, or change the Execution Blue dot color (`#2563EB` / `#3B82F6`).
