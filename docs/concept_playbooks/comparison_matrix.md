## Core Differentiators

1. **Deterministic Brand Science vs. Subjective Guesswork**
   Rather than relying on arbitrary intuition, `brando.` computes numeric scores for sound symbolism, visual letter symmetry, and numerical vibrations.

2. **Sub-35ms Security & Typosquatting Audits**
   `brando.` evaluates candidates against existing PyPI, npm, and GitHub repository names to protect your brand from supply-chain hijacking before launching.

3. **Privacy-Preserving Local Execution**
   Candidate generation and filtering happen entirely on your local machine using local CSV persistence (`brand_candidates.csv`). Domain queries are run asynchronously without sending search histories to third-party brokers.
