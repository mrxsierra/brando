# Security Policy & Vulnerability Disclosure

## Supported Versions

We issue security patches for the following versions of **`brando`**:

| Version | Supported |
| :--- | :--- |
| `0.2.x` | ✅ Supported |
| `< 0.2.0` | ❌ End of Life |

---

## Reporting a Vulnerability

We take the security of **`brando`** seriously. If you discover a security vulnerability or potential threat in our codebase or dependencies, please follow these steps:

1. **Do NOT open a public GitHub Issue.**
2. Send a detailed report via email to **`9.sunilsharma@gmail.com`**.
3. Include:
   - Description of the vulnerability and potential impact.
   - Proof-of-concept (PoC) script or steps to reproduce.
   - Any suggested remediations or patches.

### Our Commitment
- **Response**: We will acknowledge your report within 48 hours.
- **Triage & Patch**: We will work to patch the issue and publish a fix release as quickly as possible.
- **Credit**: We will credit you in the release notes unless you prefer to remain anonymous.
